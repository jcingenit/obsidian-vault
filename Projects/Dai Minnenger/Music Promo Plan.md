# Release Plan for Mixes or Tracks

## Pre-Promotion
Timeline: 5–7 days before release

Content:
- Teaser clip
- Track/mix mood description
- Behind-the-scenes post
- Story countdown
- “New mix coming soon” post
## Release
Timeline: Release day

Content:
- Main announcement post
- Reel with audio clip
- Story link
- Pin the post temporarily
- Send to close contacts, collaborators, and event organizers

Caption:
New mix is live.
Listen through the link in bio!

## Post-Release
Timeline: 1–2 weeks after release

Content:
- Highlight moments from the mix
- Share listener feedback
- Post a short breakdown of the sound
- Connect it to booking

Example CTA:
If this is the kind of energy your event needs, booking inquiries are open.
